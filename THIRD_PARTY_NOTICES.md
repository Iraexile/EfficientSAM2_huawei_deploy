# Dependencies and redistribution boundary

This public snapshot does not contain model weights, Efficient-SAM2 upstream source, ncnn binaries/source, MindSpore Lite binaries/source, Huawei SDK files, drivers, or signed applications. The build and conversion scripts refer to these separately installed dependencies. Obtain each dependency from its original distributor and follow its applicable licence and redistribution terms.

The published code and experimental reports are a derivative snapshot of the local research project. No blanket licence for third-party components is granted by this repository. A project-wide source licence has not yet been selected; this document is not a substitute for one.
